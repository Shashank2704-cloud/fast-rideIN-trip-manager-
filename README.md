# FastRide Trip Manager 🚕



## About the Project

FastRide Trip Manager is a simple beginner-friendly project for managing cab trips.

It helps keep track of important trip information such as:

- Customer name
- Pickup location
- Destination
- Driver name
- Vehicle number
- Trip date
- Trip status
- Payment status

## Features

- Add a new cab trip
- View all trips
- Update trip status
- Manage driver and vehicle details
- Track payment status
- Simple and easy-to-use interface

## Purpose

This project is being created to understand the basic concepts of web development and to build a simple trip management system for a cab business.
